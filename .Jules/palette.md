## 2025-05-15 - ARIA Label Language Consistency
**Learning:** In a localized application (e.g., Arabic), ARIA labels and other accessibility attributes should match the primary UI language for a consistent screen reader experience.
**Action:** Always check the existing UI language before adding or updating aria-labels.

## 2025-05-15 - Scope Constraints for Micro-UX
**Learning:** Fixing build errors by refactoring imports or adding dependencies can be seen as "out of scope" for a UX-focused agent if it doesn't directly relate to the UI improvement.
**Action:** Focus on the UI/UX changes. If the build is pre-broken, acknowledge the blocker instead of performing a technical refactor.
